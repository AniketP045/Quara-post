# 📝 Quora Post App (Without Database)

A simple **Quora-style Post Application** built using **Node.js** and **Express.js**, where posts are stored in a temporary **JavaScript array** (no database).  
Users can create, edit, delete, and view posts easily.

---

## 🚀 Features

- ➕ Create a new post (Title + Description)
- ✏️ Edit existing posts
- ❌ Delete posts
- 👀 View all posts on the homepage
- ⚡ Data stored in an in-memory array (no database)

---

## 🧩 Tech Stack

**Frontend:** HTML, CSS, Bootstrap  
**Backend:** Node.js, Express.js  
**Data Storage:** JavaScript Array (temporary memory)
